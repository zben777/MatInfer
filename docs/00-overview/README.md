## 理解层次与执行关系

模型层解释计算语义，Serving 层组织请求和执行，算子层拆解数学与数据变换，Backend 层给出高性能实现，Kernel 编程层描述实现工具与映射，GPU 层解释硬件约束和性能证据。

六层存在交叉。例如 KV Cache 同时关联模型表示、框架分配、Attention Backend、Kernel Layout 与 HBM 带宽。以主要问题归档，再通过链接建立联系。
