# 延伸项目

MatInfer 承载知识与经验；需要独立维护的实现可以逐渐拆为单独仓库，再由这里连接。当前只有候选方向，尚无已完成项目。

| 候选方向 | 关联知识 | 可验证的问题 |
| --- | --- | --- |
| 最小推理执行链路 | 模型、Serving、算子 | 能否追踪 Prefill / Decode、缓存和 Token 生成？ |
| 量化 KV Attention Backend | MLA、量化、CUDA / Triton | 能否减少访存，同时控制反量化开销与误差？ |
| MoE 性能实验 | Router、Grouped GEMM、DeepEP | 专家负载和通信怎样影响端到端表现？ |
| 推理性能分析案例 | Serving、Nsight、Roofline | 能否从问题建立假设，并用指标验证优化？ |

原稿提到 TurboQuant 与相关自研 Kernel，这里保留为待确认的实践线索，不把它写成已完成成果，也不预先固定算法和技术栈。

项目登记时记录：解决的问题、关联专题、仓库链接、当前状态、运行环境、可复现实验、结论与局限。独立项目有一份主要实现，主知识库维护其学习入口和总结。
