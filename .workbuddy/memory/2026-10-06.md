## `online-softmax.md` 第三轮重写：改用苏剑林（kexue.fm）文风

用户给出参考 `https://kexue.fm/archives/10091`（苏剑林《缓存与效果的极限拉扯：从MHA、MQA、GQA到MLA》），说"你学学这样的"。

**诊断（关键转折）：** 前两轮改的都不是根因。根因是**我写的是"知识的结构化展示"，他写的是"一次思考的记录"**。量化对比：他那篇全文 **0 张表格、0 个项目符号**，第 1 版我的稿子有 12 个表格 + 7 个清单 + 每节首句加粗结论。读起来像速查卡，不像有人在讲。已把完整规则固化进 `MEMORY.md` 的「写作与验证规范 → 风格基准」。

**本轮新增的内容（不只是排版）：** 补上了原稿完全缺失的**历史脉络**，这正好给了文章天然的张力和悬念：

- 起点其实是 Softmax 本身，不是 Attention。2018 年 NVIDIA（Milakov & Gimelshein）四页论文《Online normalizer calculation for softmax》（arXiv:1805.02867）想解决的是"safe softmax 要扫三遍、每元素 4 次访存"。
- 该论文自己承认灵感来自**在线计算方差的 Welford 算法**（同样面临"均值要先扫一遍"的困境）。
- 论文数字：访存 4 → 3 次/元素；V100 上 Softmax 最多 1.3x，Softmax+TopK 融合最多 5x。
- **Rabe & Staats 2021** 已用分块 Softmax 证明 Self-Attention 不需要 O(n²) 显存，但目标是峰值显存而非访存次数，速度为与标准 Attention 相当或略慢 → 反证"省显存 ≠ 少访存"。
- FlashAttention（Dao et al., 2022）把递推从 (m, ℓ) 扩展到 U，端到端加速 2~4x。
- **LSE = m + ln ℓ**：每行写回从 2 个 FP32 减到 1 个；`P_i = exp(s_i - LSE)` 把"减最大值 + 除以分母"合成一次减法。是反向传播重算 / Split-KV 归约 / Ring Attention 的共同基础。

**新标题：**《数值稳定与单遍扫描的拉扯：从 Safe Softmax 到 Online Softmax，再到 FlashAttention》。

**新结构：** 开头（事件切入）→ Softmax 的两遍 → 瓶颈 → 一遍扫描（含手算例子，改成散文叙述）→ 为什么恰好是三个状态 → 反过来：为什么不提前除掉 → 从 Softmax 到 Attention → 从串行到并行 → 只写下一个数：LSE → 小结（一段）；附录 A 参考代码 / B 工程细节 / C 面试问答。

验证：全部数字重跑脚本核对通过（11.0899 / 88.72 / O=5 / α=0.5 / β=0.25 / ℓ=2.5 / U=12.5 / 41/9 / 5.190476 / 64·128 MiB / 16 KiB / 结合律 6 种合并方式全部 5.0）。另：`math.exp(1000)` 在 Python float 里直接抛 `OverflowError`，佐证正文论点。**仍未 commit、未 push。**
