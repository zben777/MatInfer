## 关于还原质量

正文取自语雀的 **Lake 格式**（`body_asl`）而非 HTML 版（`body`）。这是关键——
语雀 HTML 版会把公式渲染成 SVG 图片、把代码块压成单反引号，导出后不可用。
Lake 格式保留了原始结构，因此：

- **公式**：真实 LaTeX（`$...$` / `$$...$$`），共 4,998 处
- **代码块**：带语言标记的围栏代码块，共 645 个
- **表格**：标准 Markdown 表格，共 2,322 行
- 导出结果 **零残留 HTML 标签**
