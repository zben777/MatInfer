## 原理与计算流程

公式排版：块公式使用 `math` 围栏，行内公式使用带反引号的美元符号语法，例如：

```text
头维度为 $`d_h`$。
```

函数名使用 `\mathrm{softmax}` 等 GitHub 可显示的写法，避免使用当前被 GitHub 禁止的 `\operatorname`。发布前需检查 GitHub 页面实际渲染；本地 LaTeX / MathJax 解析成功不能代替这一步。
